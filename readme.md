**Forge IDE.** An Electron-based desktop IDE with AI built into the editor workflow, designed for autonomous coding assistance.

**Local LLM.** A private, locally run multimodal chat system. It converts conversations into visual notes, summaries and flashcards without sending data to the cloud.

**AI Website Publishing Agent.** A Gemini-based pipeline that plans SEO content, grounds it with RAG and publishes through the WordPress REST API, with support for multiple sites.

**X-Ray Analyzer.** A YOLOv8 model trained on Google Colab for bone-fracture detection, served through a Flask web app.

**Amazon Clone.** A MERN-stack e-commerce portfolio project covering product browsing, cart and checkout flow.

**VoiceAI Assistant.** A PyQt5 desktop assistant with a black-and-green interface, voice commands, reminders, news and crypto updates.
